# H.R. Tent House & Caterers — website

Static, SEO-first website for **H.R. Tent House & Caterers**, Bengaluru.
Plain HTML/CSS/JS (GSAP + Lenis for motion), generated by one Python script, hosted free on GitHub Pages.

```
build.py          ← ALL content + settings live here. Edit, then run it.
src/assets/       ← CSS, JS, fonts, images, videos (source)
docs/             ← the finished website (generated — GitHub Pages serves this)
```

---

## 1. Put it on GitHub Pages (first time)

1. On GitHub (account **MdZeeAnsari**) create a **public** repo named exactly **`hrtenthouse-website`**.
   *(If you pick another name, change `SITE_URL` in `build.py` and run `python build.py` again.)*
2. Upload this whole folder. Easiest way, from inside this folder:
   ```bash
   git init
   git add .
   git commit -m "First version of the website"
   git branch -M main
   git remote add origin https://github.com/MdZeeAnsari/hrtenthouse-website.git
   git push -u origin main
   ```
3. Repo → **Settings → Pages** → *Build and deployment*:
   Source = **Deploy from a branch**, Branch = **main**, Folder = **/docs** → **Save**.
4. After ~1 minute the site is live at
   **https://mdzeeansari.github.io/hrtenthouse-website/**

## 2. Make changes later

1. Edit `build.py` (text, services, areas, FAQ, photos list, phone, hours…).
2. Run `python build.py` (needs Python 3 + `pip install pillow`).
3. Commit and push. GitHub updates the live site in about a minute.

Adding a photo: save it as WebP in `src/assets/img/` as `name.webp` (~1600px wide) **and** `name-thumb.webp` (~640px wide), then add a line for it in the `IMAGES` list in `build.py` with alt text and categories.

## 3. Turn on email for the enquiry form (optional, free)

Right now the form opens **WhatsApp** with the enquiry pre-filled, so it already works.
To also receive enquiries by email:

1. Go to **web3forms.com**, enter `hrtenthouse2021@gmail.com`, copy the access key from the email.
2. In `build.py` set `WEB3FORMS_KEY = "your-key-here"`, run `python build.py`, push.

## 4. Connect your own domain (when you buy one)

1. In `build.py` set:
   ```python
   SITE_URL = "https://hrtenthouse.in"
   CNAME_DOMAIN = "hrtenthouse.in"
   ```
   run `python build.py`, push.
2. At your domain registrar, add DNS records:
   - 4 × **A** records for `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - **CNAME** for `www` → `mdzeeansari.github.io`
3. Repo → Settings → Pages → Custom domain = `hrtenthouse.in` → Save → tick **Enforce HTTPS** (may take up to a day to appear).

## 5. Google (do these after it's live)

- **Google Search Console** → add the site → Sitemaps → submit `sitemap.xml`.
- **Google Business Profile** → put the website URL in the profile.
  Then in `build.py` update `maps_url` (Maps share link) and `review_url` ("Ask for reviews" link), rebuild, push.
- Name, address, phone and hours must match **exactly** on the website, Google, Justdial etc.

## Settings in `build.py`

| Setting | What it is |
|---|---|
| `SITE_URL` | Live address of the site (used for canonical links, sitemap, sharing) |
| `CNAME_DOMAIN` | Your domain, once bought (leave empty until then) |
| `WEB3FORMS_KEY` | Email key for the form (optional) |
| `BIZ` | Name, address, phone, WhatsApp, email, hours, map pin, Google links |
| `SERVICES` / `AREAS` / `GENERAL_FAQ` | Page content |
| `IMAGES` / `VIDEOS` | Photos (alt text + gallery filters) and videos |

Testimonials section is ready to add once there are 3+ real Google reviews (see the comment in `home()`).
